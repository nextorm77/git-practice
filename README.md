# Git Practice (git-practice)

이 저장소는 Git 및 GitHub 버전 관리 시스템의 다양한 기능을 실습하고 익히기 위해 만들어진 연습용 프로젝트입니다.

## 📂 디렉토리 및 파일 구조

이 프로젝트는 다음과 같은 구조로 이루어져 있으며, 각 파일들은 특정 Git 명령어나 상황(브랜치 병합, 충돌 해결 등)을 연습하는 데 사용할 수 있습니다.

* `.gitignore`: Git이 추적하지 않을 파일이나 디렉토리를 지정합니다.
* **기능 연습용 파일**: `feature1.txt`, `feature2.txt`, `feature3.txt` 
  * 새로운 브랜치를 생성하고 병합(Merge)하는 과정을 연습하기 위한 텍스트 파일입니다.
* **설정 및 데이터 연습용 파일**: `jaguars.yaml`, `leopard.yaml`, `panthers.yaml`, `pumas.yaml`, `tigers.yaml`
  * 파일 내용 수정, 커밋 내역 관리 및 충돌(Conflict) 발생 및 해결을 실습하기 위한 YAML 파일입니다.
* **하위 디렉토리 파일**: `dir1/subFile1.txt`, `dir1/dir2/subFile2.txt`
  * 중첩된 디렉토리 환경에서 파일의 이동, 이름 변경 및 경로 추적을 연습하기 위한 디렉토리 구조입니다.
